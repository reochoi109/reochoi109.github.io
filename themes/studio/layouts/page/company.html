ABOUT ME

{{ if $isKo }} 자기소개
{{ else }} Finding answers
in unfamiliar territory. {{ end }}

{{ if $isKo }}

무대 위 배우에서 백엔드 개발자까지, 새로운 환경에서도 직접 부딪히며 답을 찾아온 최신욱입니다.

연극을 처음 시작한 것은 제 자신을 바꿔보고 싶어서였습니다. 당시 저는 사람들 앞에 나서는 것조차 어려워할 만큼 소극적이었지만, 그런 제 모습을 바꾸기 위해 연극에 도전했습니다. 작은 도전으로 시작한 연극은 약 10년간 이어졌고, 대학에서는 연극영화를 전공하며 연기뿐만 아니라 조명, 무대 제작 등 다양한 역할을 경험했습니다. 여러 사람과 하나의 공연을 만들어가며 협업하는 법을 배웠고, 3학년 때 학과 성적 1등과 거창전국대학연극제 남자연기대상이라는 결과도 얻었습니다.

무엇보다 연극을 통해 처음에는 부족하더라도 포기하지 않고 꾸준히 노력하면 결국 달라질 수 있다는 것을 배웠습니다. 사람들 앞에 서는 것조차 어려워했던 제가 계속 무대에 오르며 부족한 점을 하나씩 채워갔고, 오랜 시간 노력한 끝에 결과까지 만들어낼 수 있었습니다. 이 경험은 이후 새로운 일을 시작할 때도 쉽게 포기하지 않고 끝까지 해보는 태도의 바탕이 되었습니다.

이러한 태도는 개발자로 전환할 때도 이어졌습니다. 비전공자로 개발을 처음부터 배우고 인턴으로 실무를 시작했기에 모르는 것도 많았습니다. 문제가 생기면 먼저 스스로 고민하고 자료를 찾아봤고, 혼자 해결하기 어려울 때는 동료들에게 적극적으로 질문했습니다. 쉽게 답이 나오지 않는 문제는 여러 가능성을 살펴보고 하나씩 확인하며 원인을 찾아갔습니다.

그렇게 인턴에서 정규직으로 전환되었고, 새로운 서비스를 처음부터 설계하고 개발하는 업무까지 맡게 되었습니다. 마지막 인사평가에서는 파트장을 제외한 백엔드 구성원 중 가장 높은 평가를 받았습니다. 개발자로 일하며 가장 크게 익힌 것은 문제가 발생했을 때 현상만 보고 해결책부터 찾기보다, 원인을 논리적으로 좁혀가는 방식​이었습니다. 에러나 예상하지 못한 결과가 발생하면 로그와 데이터를 확인하고, 가능한 원인을 여러 가설로 나눈 뒤 하나씩 검증하며 문제의 범위를 좁혀갔습니다. 이를 반복하면서 복잡한 문제도 작은 단위로 나누어 원인을 찾고, 근거를 바탕으로 해결하는 사고방식을 익혔습니다.

회사를 나온 뒤에는 직접 웹서비스를 만들고 스마트스토어도 운영했습니다. 웹사이트에서는 게시글의 제목과 태그를 바꿔보았고, 스마트스토어에서도 상품명과 검색 키워드를 수정하며 노출 순위를 확인했습니다. 작은 변화에도 노출 결과가 달라지는 것을 보면서, 직접 시도하고 결과를 확인하며 개선해나가는 과정에 흥미를 느꼈습니다. 이러한 경험을 계기로 퍼포먼스 마케팅을 새로운 진로로 선택했습니다.

연극과 개발이라는 서로 다른 환경에서도 새로운 일을 직접 부딪혀 익히고, 문제를 하나씩 해결하며 결과를 만들어왔습니다. 이제는 그 과정에서 쌓은 끈기와 문제 해결 방식을 바탕으로, 제가 한 판단과 실행을 고객의 반응과 비즈니스 성과로 연결하고 싶습니다. 결과를 직접 확인하고 그 안에서 다시 문제를 찾아 더 나은 성과를 만들어가는 퍼포먼스 마케터가 되고자 합니다.

TRANSITION

{{ if $isKo }} 전환 배경 {{ else }} Career transition {{ end }}

{{ if $isKo }}
01

퍼포먼스 마케팅에 관심을 갖게 된 계기

백엔드 개발자로 API와 데이터 파이프라인을 만들었고, 이후 Molru·SchemaPad·Slow Mind를 직접 기획하고 제작했습니다. 서비스를 출시하면서 좋은 제품을 만드는 것만큼 고객이 제품을 발견하고 선택하게 만드는 과정이 중요하다는 점에 관심을 갖게 되었습니다. 검색 노출을 고려해 사이트 구조와 콘텐츠를 설계한 경험은 SEO와 사용자 유입을 더 깊이 탐구하는 계기가 되었습니다.

과일을 판매하는 스마트스토어를 운영하며 상품 등록부터 판매 채널 관리까지 직접 경험했습니다. 전문적으로 광고를 집행해 성과를 만든 경험은 아니지만, 제품이 고객에게 노출되고 구매로 이어지는 과정을 판매자 관점에서 바라볼 수 있었습니다. 웹 서비스 제작과 판매 채널 운영 경험을 통해 관심은 자연스럽게 고객의 유입과 전환을 다루는 퍼포먼스 마케팅으로 확장되었습니다.

02

경험에서 이어지는 강점

  • 로그와 데이터를 바탕으로 문제의 원인을 좁히고, 해결책을 적용한 뒤 결과를 검증하는 방식에 익숙합니다.
  • 웹 서비스의 구조와 데이터 흐름을 이해해 측정과 전환 추적 과정에서 기술적인 맥락을 빠르게 파악할 수 있습니다.
  • 낯선 환경에서도 필요한 내용을 질문하고 학습하며, 배운 것을 실제 결과로 연결해 왔습니다.
  • 경험과 지식을 동료와 공유하고, 서로 다른 역할의 구성원과 목표를 맞추며 협업합니다.
03

성장하고 있는 방향

현재는 광고 매체와 핵심 지표, 전환 추적, 성과 분석에 대한 이해를 넓혀가고 있습니다. 아직 충분한 실무 경험을 갖추지는 않았지만, 수치를 단순한 결과로 받아들이기보다 그 원인을 질문하고 다음 실행을 고민하는 태도를 기르고 있습니다. 앞으로 다양한 경험을 통해 분석을 실행으로 연결하는 퍼포먼스 마케터로 성장하고 싶습니다. 장기적으로는 마케팅 전문성에 데이터와 기술에 대한 이해를 더해, 비즈니스의 문제와 기회를 먼저 발견하고 제안하는 사람이 되는 것이 목표입니다.
