ABOUT ME

{{ if $isKo }} 자기소개
{{ else }} Finding answers
in unfamiliar territory. {{ end }}

{{ if $isKo }}

무대 위 배우에서 백엔드 개발자까지, 새로운 환경에서도 직접 부딪히며 답을 찾아온 최신욱입니다.

연극을 처음 시작한 것은 제 자신을 바꿔보고 싶어서였습니다. 당시 저는 사람들 앞에 나서는 것조차 어려워할 만큼 소극적이었지만, 그런 제 모습을 바꾸기 위해 연극에 도전했습니다. 작은 도전으로 시작한 연극은 약 10년간 이어졌고, 대학에서는 연극영화를 전공하며 연기뿐만 아니라 조명, 무대 제작 등 다양한 역할을 경험했습니다. 여러 사람과 하나의 공연을 만들어가며 협업하는 법을 배웠고, 3학년 때 학과 성적 1등과 거창전국대학연극제 남자연기대상이라는 결과도 얻었습니다.

무엇보다 연극을 통해 처음에는 부족하더라도 포기하지 않고 꾸준히 노력하면 결국 달라질 수 있다는 것을 배웠습니다. 사람들 앞에 서는 것조차 어려워했던 제가 계속 무대에 오르며 부족한 점을 하나씩 채워갔고, 오랜 시간 노력한 끝에 결과까지 만들어낼 수 있었습니다. 이 경험은 이후 새로운 일을 시작할 때도 쉽게 포기하지 않고 끝까지 해보는 태도의 바탕이 되었습니다.

이러한 태도는 개발자로 전환할 때도 이어졌습니다. 비전공자로 개발을 처음부터 배우고 인턴으로 실무를 시작했기에 모르는 것도 많았습니다. 문제가 생기면 먼저 스스로 고민하고 자료를 찾아봤고, 혼자 해결하기 어려울 때는 동료들에게 적극적으로 질문했습니다. 쉽게 답이 나오지 않는 문제는 여러 가능성을 살펴보고 하나씩 확인하며 원인을 찾아갔습니다.

그렇게 인턴에서 정규직으로 전환되었고, 새로운 서비스를 처음부터 설계하고 개발하는 업무까지 맡게 되었습니다. 마지막 인사평가에서는 파트장을 제외한 백엔드 구성원 중 가장 높은 평가를 받았습니다. 개발자로 일하며 가장 크게 익힌 것은 문제가 발생했을 때 현상만 보고 해결책부터 찾기보다, 원인을 논리적으로 좁혀가는 방식​이었습니다. 에러나 예상하지 못한 결과가 발생하면 로그와 데이터를 확인하고, 가능한 원인을 여러 가설로 나눈 뒤 하나씩 검증하며 문제의 범위를 좁혀갔습니다. 이를 반복하면서 복잡한 문제도 작은 단위로 나누어 원인을 찾고, 근거를 바탕으로 해결하는 사고방식을 익혔습니다.

회사를 나온 뒤에는 직접 웹서비스를 만들고 스마트스토어도 운영했습니다. 웹사이트에서는 게시글의 제목과 태그를 바꿔보았고, 스마트스토어에서도 상품명과 검색 키워드를 수정하며 노출 순위를 확인했습니다. 작은 변화에도 노출 결과가 달라지는 것을 보면서, 직접 시도하고 결과를 확인하며 개선해나가는 과정에 흥미를 느꼈습니다. 이러한 경험을 계기로 퍼포먼스 마케팅을 새로운 진로로 선택했습니다.

연극과 개발이라는 서로 다른 환경에서도 새로운 일을 직접 부딪혀 익히고, 문제를 하나씩 해결하며 결과를 만들어왔습니다. 이제는 그 과정에서 쌓은 끈기와 문제 해결 방식을 바탕으로, 제가 한 판단과 실행을 고객의 반응과 비즈니스 성과로 연결하고 싶습니다. 결과를 직접 확인하고 그 안에서 다시 문제를 찾아 더 나은 성과를 만들어가는 퍼포먼스 마케터가 되고자 합니다.

WHY MADUP

{{ if $isKo }} 지원동기 {{ else }} Why MADUP {{ end }}

{{ if $isKo }}

퍼포먼스 마케팅에 관심을 가지면서 가장 흥미롭게 느낀 부분은 단순히 숫자를 보고 결과를 평가하는 것이 아니라, 왜 그런 결과가 나왔는지 질문하고 무엇이 문제인지 파악한 뒤 다음 액션을 찾아가는 과정이었습니다. 개발과 개인 서비스를 운영하며 익힌 문제 해결의 사고방식을 이제는 고객과 비즈니스의 성과를 만드는 데 활용하고 싶었습니다.

그중에서도 매드업에 지원한 이유는 데이터와 AI를 활용해 마케터가 더 중요한 판단과 전략에 집중할 수 있는 환경을 만들고 있기 때문입니다. AI 에이전트를 실제 캠페인 운영에 활용해 데이터 분석부터 입찰 최적화, 운영 자동화까지 고도화하고, 반복적인 업무를 줄이면서 성과를 분석하고 다음 액션을 결정하는 데 집중한다는 점이 제가 매드업에서 퍼포먼스 마케팅을 시작하고 싶은 가장 큰 이유입니다.

저 역시 개발자로 일하며 반복되는 업무를 줄이는 자동화에 관심을 가져왔습니다. 실제로 퍼포먼스 마케터가 PC와 모바일에서 관리 중인 검색광고의 노출 위치를 반복적으로 확인하는 업무를 줄일 수 있도록, 이를 자동으로 확인하는 도구 개발을 도운 경험도 있습니다. 큰 프로젝트는 아니었지만 실제 마케터의 반복 업무를 기술로 줄여본 경험이 있다는 점에서, 매드업이 기술과 자동화를 활용하는 방식에도 자연스럽게 관심이 갔습니다.

물론 개발 경험만으로 퍼포먼스 마케팅을 잘할 수 있다고 생각하지 않습니다. 광고 매체와 지표, 고객 행동, 캠페인 운영과 최적화는 새롭게 익혀야 할 영역입니다. 다만 비전공 개발자로 시작해 실무에 적응하고 역할을 넓혀왔던 것처럼, 퍼포먼스 마케팅에서도 필요한 역량을 빠르게 익히고 실행에 옮기겠습니다. 개발을 통해 쌓은 문제 해결 방식과 기술 활용 경험까지 더해, 데이터를 바탕으로 더 나은 다음 액션을 제안하고 실제 성과 개선에 기여하는 마케터가 되고자 매드업에 지원했습니다.

{{ if $isKo }} 입사 후

입사 후 가장 먼저 해야 할 일은 퍼포먼스 마케터로서 실무에 빠르게 적응하는 것이라고 생각합니다. 다양한 광고 매체와 주요 지표, 캠페인 운영 방식과 리포트 작성 과정을 빠르게 익히고 실제 업무에 적용하겠습니다. 성과가 올랐거나 떨어졌다는 결과에서 멈추지 않고 왜 그런 결과가 나왔는지 질문하고, 데이터를 통해 원인을 파악한 뒤 다음 액션을 제안할 수 있는 AE로 성장하겠습니다.

초기에는 주어진 업무를 정확하게 수행하는 것부터 시작하되, 결과를 보고 스스로 다음 단계를 준비할 수 있는 수준까지 빠르게 올라가겠습니다. 소재 방향성, 캠페인 최적화, 성과 분석 등 실제 업무를 경험하며 가설을 세우고 실행한 뒤 결과를 확인하는 과정을 반복하고, 그 과정에서 실제 성과 개선에 기여하겠습니다.

실무에 충분히 적응한 이후에는 개발자로서 익힌 문제 해결 방식과 기술 활용 경험을 자연스럽게 더하겠습니다. 반복적으로 시간을 쓰는 업무가 있다면 AI와 자동화를 활용해 효율화하고, 필요한 데이터를 더 효과적으로 다룰 수 있는 방법이 있다면 직접 찾아 적용하겠습니다. 기술을 사용하는 것 자체가 목적이 아니라, 확보한 시간과 정보를 더 중요한 판단과 전략에 활용하겠습니다.

궁극적으로는 광고주의 요청을 받아 캠페인을 운영하는 데 그치지 않고, 먼저 문제와 기회를 발견하고 다음 액션을 제안할 수 있는 AE로 성장하겠습니다. 빠르게 익히고 실행하며 성과를 만들고, 그 결과에서 다시 더 나은 방법을 찾아가는 퍼포먼스 마케터가 되는 것입니다.
