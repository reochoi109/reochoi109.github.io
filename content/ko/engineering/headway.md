## 프로젝트 개요

카메라 기반 차량 검지 데이터를 이용해 같은 차로를 연속으로 통과한 차량의 시간 간격과 실제 차량 사이의 간격을 계산하는 기능을 개발했습니다. 분석 결과는 여러 참여 기업이 공동 사용하는 데이터베이스에 제공되어 교통 신호 회사의 신호 최적화 기초 자료로 활용됐습니다.

## 분석 방식

- 차량 검지 데이터를 차로별로 분류하고 통과 시각순으로 정렬
- 같은 차로를 연속으로 통과한 차량 쌍 생성
- **Headway**: 앞 차량과 뒤 차량의 통과 시각 차이
- **GAP**: Headway에서 차량 길이와 속도로 계산한 점유 시간을 제외한 간격
- 같은 신호 구간의 차량만 분석하고 비정상 값 제외
- 차로·신호 주기별 평균·합계와 유효 데이터 집계
- ODBC를 통해 공동 Tibero 데이터베이스에 결과 적재

## 카메라 기반 검지 데이터 보정

교차로마다 카메라 위치와 화각이 다르고, 차량이 겹치거나 가까이 주행할 때 검지 박스와 차량 ID가 올바르게 이어지지 않는 사례가 있었습니다.

실제 영상과 검지 결과를 직접 대조하면서 교차로별 보정값을 조정했고, 분석 단계에서는 신호 구간과 이상치 조건을 적용해 분석 대상 데이터를 구분했습니다.

## 결과 활용

차로와 신호 주기별로 집계된 결과를 공동 데이터베이스에 제공해 교통 신호 회사가 신호 최적화를 검토하는 기초 자료로 사용할 수 있도록 했습니다.
