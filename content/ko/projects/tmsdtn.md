## 프로젝트 개요

시뮬레이션 서버와 클라이언트 사이에서 분석 요청, 진행 상태와 결과 수집, 교통 데이터 가공과 전달을 담당하는 중계 서버입니다. 프로젝트의 백엔드 전체를 직접 설계·개발했습니다.

## 담당 업무

- 분석 요청·진행 상태·결과를 조회하는 REST API와 공통 응답 형식 구현
- 교통량·서비스 수준(LOS)·탄소배출량 등 시뮬레이션 결과 조회 API 구현
- Kafka와 작업별 ID를 이용한 장시간 시뮬레이션 요청·결과 비동기 처리
- 생성된 교통 분석 결과를 수신·저장하고 클라이언트 요구사항에 맞는 응답 형태로 가공
- 저장된 결과를 여러 사용자에게 WebSocket으로 순차 전달하고 시작·종료 상태 동기화

## 데이터 처리 방식 개선

15분 분량의 시뮬레이션 결과는 9,000개 시점 데이터로 나뉘어 전달됩니다. 기존에는 전체 수신이 끝날 때까지 모든 데이터를 메모리에 쌓아 둔 뒤 한꺼번에 파일로 생성해 메모리 사용량이 커졌습니다.

각 시점 데이터를 수신할 때마다 파일에 순차적으로 기록하고, 기록한 데이터는 즉시 메모리에서 제거하도록 변경했습니다. 이를 통해 전체 데이터를 한 번에 보관하지 않고 현재 처리 중인 데이터만 메모리에 유지했습니다.

결과 데이터는 JSON 파일로 생성한 뒤 tar.gz로 압축해 보관·전달했습니다.
