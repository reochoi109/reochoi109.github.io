## 핵심 경험

- 디지털 트윈 중계 서버의 REST API, Kafka 요청·결과 처리, 데이터 저장과 WebSocket 전달을 전담 설계·개발
- 15분 분량의 9,000개 시점 데이터를 수신 즉시 파일에 기록하고 메모리에서 제거하는 방식으로 변경
- 카메라 영상과 차량 검지 결과를 대조해 교차로별 보정값을 조정하고 차량 간 통과 간격 분석
- 사내 공용 Go 모듈을 설계·개발하고 Git tag/go.mod 기반으로 배포한 뒤 Confluence에 문서화

## 일하는 방식

- 실제 코드와 데이터를 확인한 뒤 설명할 수 있는 사실만 결과로 기록합니다.
- 기존 서비스는 운영에 영향을 주지 않도록 구조와 데이터 흐름을 먼저 파악한 뒤 변경합니다.
- 반복되는 구현은 공용화하고 다른 개발자가 사용할 수 있도록 문서로 남깁니다.
