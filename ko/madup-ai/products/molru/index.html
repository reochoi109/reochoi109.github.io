Molru

한국어 학습자를 위한 읽기 중심 콘텐츠 매거진

영어권 한국어 학습자가 한국의 일상과 문화에 관한 짧은 글을 부담 없이 읽으며 실제 한국어를 접할 수 있도록 만든 콘텐츠 매거진입니다. 오디오, 번역, 단어 설명을 필요한 순간에만 사용할 수 있도록 읽기 경험 안에 구성했습니다.

개요

Molru는 영어권 한국어 학습자가 한국의 일상과 문화를 짧은 글로 읽는 콘텐츠 매거진입니다. 한국어 원문을 중심에 두고 오디오, 번역, 단어 설명은 필요한 순간에만 사용할 수 있도록 구성했습니다.

배경

한국어를 공부할 때 항상 문법이나 단어를 외우는 콘텐츠만 필요한 것은 아니라고 생각했습니다.

때로는 한국 사람들이 실제로 사용하는 표현이나 일상, 문화에 관한 짧은 글을 가볍게 읽는 것만으로도 한국어를 계속 접할 수 있습니다. 하지만 학습자를 위한 콘텐츠는 교재처럼 구성된 경우가 많고, 반대로 일반적인 한국 콘텐츠는 아직 한국어에 익숙하지 않은 학습자가 읽기에는 어려울 수 있습니다.

그래서 한국어를 배우는 사람이 부담 없이 읽을 수 있는 작은 콘텐츠 매거진을 만들어보면 어떨까라는 생각에서 Molru를 시작했습니다.

한국의 일상과 문화, 사람들의 이야기, 최근 표현을 짧은 아티클로 제공하고, 읽다가 필요한 순간에만 오디오와 번역, 단어 설명을 확인할 수 있도록 구성했습니다.

학습 기능 자체보다 한국어로 된 읽을거리를 계속 접할 수 있는 경험을 만드는 것을 중심에 두었습니다.

기획

사용자와 사용 맥락

Molru는 한국어를 공부하고 있지만 교재나 강의가 아닌 조금 더 가벼운 방식으로 한국어를 접하고 싶은 영어권 학습자를 주요 독자로 설정했습니다.

  • 한국의 일상과 문화에 관심이 있는 한국어 학습자
  • 교재 밖에서 실제 사용되는 표현을 접하고 싶은 사람
  • 긴 학습 세션보다 짧은 글을 부담 없이 읽고 싶은 사람
  • 한국어 원문을 읽되 어려운 부분에서만 도움을 받고 싶은 사람
  • 언어뿐 아니라 표현이 사용되는 상황과 배경도 함께 알고 싶은 사람

사용자가 Molru에 들어왔을 때 ‘공부를 시작한다’기보다 관심 있는 글 하나를 골라 읽는다는 느낌을 받을 수 있도록 서비스의 성격을 잡았습니다.

콘텐츠 기획

Molru의 콘텐츠는 문법이나 어휘 종류가 아니라 한국어를 접하는 맥락을 기준으로 네 가지 주제로 나누었습니다.

Daily Korean에서는 실제 생활에서 접할 수 있는 한국어와 일상적인 상황을 다룹니다.

K-Culture에서는 음식, 생활 방식, 관습처럼 한국어를 이해할 때 함께 알면 좋은 문화적 배경을 다룹니다.

Stories에서는 개인적인 경험과 이야기를 중심으로 조금 더 자연스러운 읽을거리를 제공합니다.

Korean Now에서는 최근 사용되는 표현이나 유행처럼 지금의 한국에서 접할 수 있는 언어와 현상을 다룹니다.

각 아티클에는 주제와 함께 난이도와 예상 읽기 시간을 표시했습니다.

많은 콘텐츠를 단순히 나열하기보다 무슨 내용인지, 지금 읽을 수 있는 수준인지, 얼마나 걸리는지를 빠르게 판단하고 글을 선택할 수 있도록 구성했습니다.

기획 기준

Molru에서는 학습 기능을 얼마나 많이 제공할 것인지보다 읽는 경험을 얼마나 방해하지 않을 것인지를 중요하게 생각했습니다.

  • 콘텐츠 자체가 읽을거리로서 흥미로울 것
  • 한국의 실제 일상과 문화, 표현을 소재로 사용할 것
  • 한국어 원문을 읽는 경험을 중심에 둘 것
  • 하나의 글을 부담 없이 읽을 수 있는 길이로 구성할 것
  • 자연스러운 한국어 음성을 글과 함께 들을 수 있도록 할 것
  • 번역과 단어 설명은 필요한 경우에만 사용할 수 있도록 할 것
  • 학습 기능 때문에 글을 읽는 흐름이 끊기지 않을 것
  • 하나의 글을 읽은 뒤 다른 콘텐츠를 쉽게 발견할 수 있도록 할 것

사용자가 서비스를 계속 조작하는 것보다 관심 있는 글을 발견하고 읽는 것이 가장 중요한 행동이 되도록 구성했습니다.

와이어프레임

공개 라우트와 읽기 경험의 주요 상태를 전체 페이지 단위로 설계했습니다.

주요 기능

콘텐츠 경험

Molru의 기본 사용 흐름은 일반적인 블로그나 온라인 매거진처럼 단순하게 만들었습니다.

사용자는 홈이나 Topics에서 관심 있는 콘텐츠를 발견하고 하나의 아티클을 선택해 읽을 수 있습니다.

읽는 과정에서 도움이 필요한 경우에만 오디오, 번역, 단어 설명을 사용할 수 있고, 별도의 학습 기능을 사용하지 않고 글만 읽어도 Molru의 콘텐츠를 이용할 수 있습니다.

오디오와 번역, Vocabulary는 반드시 거쳐야 하는 학습 단계가 아니라 읽다가 필요할 때 선택할 수 있는 보조 기능으로 두었습니다.

읽기와 듣기를 함께

개별 아티클에서는 한국어 원문과 함께 전체 내용을 들을 수 있는 Story Audio를 제공합니다.

오디오가 별도의 학습 페이지로 분리되지 않고 글과 같은 화면에서 재생되도록 했으며, Timestamp를 통해 현재 듣고 있는 문장을 본문에서도 함께 따라갈 수 있도록 구성했습니다.

사용자는 글만 읽을 수도 있고, 오디오만 먼저 들어볼 수도 있으며, 한국어 문장을 따라 읽으면서 동시에 발음을 들을 수도 있습니다.

정해진 학습 순서를 따르게 하기보다 하나의 콘텐츠를 각자의 방식으로 읽고 들을 수 있도록 했습니다.

필요할 때만 사용하는 학습 기능

한국어 학습자를 위한 콘텐츠이지만 번역과 단어 설명을 처음부터 모두 노출하지 않았습니다.

기본적으로 한국어 원문을 중심으로 읽고, 이해하기 어려운 경우 Reading Options에서 Translation과 Vocabulary를 직접 활성화할 수 있도록 했습니다.

Translation을 활성화하면 각 한국어 문장 아래에서 영어 번역을 확인할 수 있습니다.

Vocabulary를 활성화하면 주요 단어가 문장 안에서 표시되고, 선택한 단어의 발음과 의미, 품사와 사용 예시를 읽고 있던 위치에서 바로 확인할 수 있습니다.

별도의 단어장이나 학습 화면으로 이동하기보다 모르는 부분을 확인한 뒤 바로 읽던 글로 돌아갈 수 있는 것을 중요하게 봤습니다.

학습 기능은 콘텐츠를 대신하는 것이 아니라 읽기의 마찰을 줄여주는 보조 도구로 사용했습니다.

글을 읽은 뒤

하나의 아티클을 읽은 이후에는 본문에서 사용된 주요 단어와 표현을 Learning Notes에서 다시 확인할 수 있도록 했습니다.

본문 안의 Vocabulary가 읽는 도중 모르는 단어를 확인하기 위한 기능이라면, Learning Notes는 글을 다 읽은 뒤 이번 콘텐츠에서 등장했던 표현을 가볍게 다시 살펴볼 수 있는 영역으로 구분했습니다.

다만 이를 별도의 학습 과정으로 강제하지 않고, 원하는 사용자가 추가로 확인할 수 있는 콘텐츠의 일부로 두었습니다.

또한 하나의 글에서 경험이 끝나지 않도록 다른 아티클로 이동할 수 있는 구조를 함께 제공했습니다.

설계 및 구현

콘텐츠 탐색과 유입

Molru는 사용자가 반드시 서비스 이름을 알고 홈 화면으로 들어오는 것만을 전제로 하지 않았습니다.

한국어 표현이나 한국 문화에 관심을 가진 사용자가 검색을 통해 하나의 아티클을 먼저 발견할 수도 있다고 보고, 각각의 글이 독립적인 읽을거리로 기능할 수 있도록 구성했습니다.

검색을 통해 특정 글에 바로 들어오더라도 해당 콘텐츠 안에서 Molru의 읽기 경험을 그대로 사용할 수 있고, 글을 읽은 이후에는 다른 아티클과 주제로 이동할 수 있도록 했습니다.

홈에서는 최신 콘텐츠와 여러 주제를 발견할 수 있도록 하고, Topics에서는 Daily Korean, K-Culture, Stories, Korean Now를 기준으로 원하는 읽을거리를 탐색할 수 있도록 구성했습니다.

이를 통해 콘텐츠 발견 → 읽기 → 다른 콘텐츠 발견이 반복될 수 있는 가벼운 매거진 형태의 구조를 만들고자 했습니다.

사이트 개발뿐 아니라 콘텐츠 분류, 아티클 형식, 난이도와 읽기 시간, Story Audio, Timestamp, Translation, Vocabulary, Learning Notes를 하나의 읽기 경험으로 연결했습니다. 각 아티클을 독립적인 웹페이지로 구성해 검색 유입 이후에도 다른 글과 주제로 자연스럽게 이동할 수 있도록 했습니다.

결과

제작과 공개

Molru는 사이트 개발뿐 아니라 콘텐츠를 어떤 방식으로 보여줄 것인지까지 함께 기획한 프로젝트입니다.

콘텐츠 주제와 분류, 아티클 형식, 난이도와 읽기 시간, Story Audio, Timestamp, Translation, Vocabulary, Learning Notes와 콘텐츠 탐색 구조를 하나의 읽기 경험으로 구성했습니다.

각 아티클이 독립적인 웹페이지로 존재하면서 다른 콘텐츠와 연결될 수 있도록 사이트 구조를 만들고 실제 웹서비스로 구현해 공개했습니다.

개인정보 처리방침, 이용정책, 문의 페이지 등 공개 웹서비스 운영에 필요한 기본 페이지도 함께 구성했습니다.

현재도 별도의 회원가입이나 설치 없이 웹에서 바로 읽을 수 있는 무료 콘텐츠 사이트로 공개 운영하고 있습니다.

회고

Molru에서는 한국어 학습 서비스를 만드는 것보다 한국어를 배우는 사람이 가볍게 찾아와 읽을 수 있는 공간을 만드는 것에 더 가까운 방향을 선택했습니다.

모든 방문자가 단어를 외우거나 학습 기능을 사용할 필요는 없습니다. 흥미로운 제목을 보고 들어와 한국의 일상에 관한 짧은 글 하나를 읽고 나가는 것만으로도 Molru를 충분히 사용할 수 있다고 생각했습니다.

그래서 학습 기능을 전면에 내세우기보다 콘텐츠를 먼저 배치하고, 도움이 필요한 순간에만 오디오와 번역, 단어 설명이 등장하도록 설계했습니다.

이 프로젝트를 통해 기능을 구현하는 것뿐 아니라 누구에게 어떤 콘텐츠를 보여줄 것인지, 어떻게 발견하게 할 것인지, 읽는 동안 어떤 도움을 제공할 것인지, 다음 콘텐츠로 어떻게 이어지게 할 것인지까지 하나의 서비스 경험으로 직접 기획하고 구현했습니다.

개인적으로 시작한 프로젝트지만, 콘텐츠의 주제와 정보 구조부터 읽기 경험과 학습 보조 기능, 웹서비스 구현과 공개까지 직접 연결해본 콘텐츠 중심의 제품 프로젝트로 남겼습니다.
