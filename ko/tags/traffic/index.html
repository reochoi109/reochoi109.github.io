자사 교통관제시스템(TMS) 백엔드 개발·유지보수

2026. 8. 28.

업무 개요 교통관제시스템(TMS)은 라온로드의 핵심 자사 솔루션입니다. 재직 기간 전체에 걸쳐 TMS 백엔드의 기존 코드와 데이터 흐름을 파악하고, 요구사항 반영과 신규 기능 개발, 운영 이슈 대응을 담당했습니다. TMS 주요 개발 TMS-Gateway: 기존 마이크로서비스 구조의 API 진입점에서 reverse proxy, 사용자·권한, 요청 제한과 실시간 알림 기능을 유지보수하고 필요한 기능을 추가했습니다. TMS-DTN 중계 서버: 교통 시뮬레이션 요청과 결과를 Kafka로 비동기 처리하고, 정적 분석 지표와 동적 트윈 데이터를 API와 WebSocket으로 제공했습니다. Headway·GAP 분석 기능: 차량 검지 데이터를 이용해 차두시간과 차간시간을 계산하고, 신호 주기별 결과를 집계해 공동 데이터베이스에 제공했습니다.

TMS-DTN 디지털트윈 중계 서버 개발

2026. 5. 2.

프로젝트 개요 DTN(Digital Twin Network)은 실제 교통 데이터를 기반으로 도로의 교통 흐름을 디지털 공간에 재현하고, 운영 대안을 가상으로 실험하는 교통 디지털트윈 시스템입니다. 저는 사용자 클라이언트와 교통 시뮬레이션 서버 사이를 연결하는 중계 서버를 구축했습니다. 중계 서버는 분석 요청을 시뮬레이션 작업으로 전달하고, 실행 상태와 결과를 수집·가공·저장한 뒤 API와 WebSocket으로 클라이언트에 제공합니다. 프로젝트 목적 DTN의 목적은 신호 운영 변경이나 사고·공사 같은 시나리오를 실제 도로에 적용하기 전에 검증하고, 교통량·통행속도·대기행렬·서비스 수준(LOS)·탄소배출량 등의 변화를 비교해 교통정책의 판단 근거를 제공하는 것입니다.

TMS 차량 통과 간격(Headway·GAP) 분석 기능

2026. 4. 28.

프로젝트 개요 교통관제시스템(TMS) 내부에서 차량 검지 데이터를 활용한 Headway·GAP 분석 기능을 개발했습니다. 검지 시각·속도·차종·차로·신호 주기를 결합해 유효한 차량 쌍을 선별하고, 분석 결과를 차로와 신호 주기 단위의 지표로 만들었습니다. 프로젝트 목적 차량의 통과 시간 간격을 정량화해 신호 운영과 최적화 분석에 사용할 기초 데이터를 만드는 것이 목적이었습니다. 담당 역할 차량 검지 데이터의 분류·계산 로직, 신호 구간 처리, 카메라 설치 환경별 데이터 보정, 결과 집계와 Tibero 데이터베이스 연계를 개발했습니다. 주요 구현 분석 흐름 차량 통과 간격 분석 흐름 차량 검지 데이터 수신 차로별 분류 통과 시각순 정렬 연속 차량 쌍 생성 Headway·GAP 계산 신호 주기별 집계 Tibero DB 적재 Headway와 GAP 계산 방법 이 프로젝트에서 계산한 값은 차량 사이의 물리적 거리인 차두거리가 아니라, 한 검지 지점을 기준으로 한 시간 간격입니다.
