PhotoAI

급한 면접 사진을 위한 AI 프로필 제작 서비스

정면 사진 한 장과 몇 가지 옵션으로 면접용 프로필 사진을 만드는 서비스입니다. 결제부터 결과 편집까지 전체 흐름을 구현했지만 핵심 품질 기준을 안정적으로 충족하지 못해 출시를 보류했습니다.

개요

PhotoAI는 정면 사진 한 장과 몇 가지 선택 항목으로 면접용 프로필 사진을 제작하는 AI 서비스입니다. 결제, 비동기 생성, 결과 비교와 구도 편집까지 실제 운영 가능한 흐름을 구현했지만 핵심 품질 기준을 안정적으로 충족하지 못해 출시를 보류했습니다.

배경

지원 마감이나 면접 일정이 가까운데 새 프로필 사진이 필요한 순간이 있습니다. 하지만 사진관을 예약하고 방문하려면 시간과 비용이 들고, 당장 사진이 필요한 사람에게는 이 과정 자체가 부담이 될 수 있습니다.

정면 사진 한 장만으로 사진관에 방문하는 과정과 비용을 줄일 수 있지 않을까?

이 질문에서 PhotoAI를 시작했습니다.

사용자가 원하는 결과는 재미있는 AI 이미지가 아니라, 지원서에 실제로 사용할 수 있을 만큼 단정하면서도 본인다운 사진이라고 정의했습니다.

기획

사용자와 사용 맥락

주요 사용자는 새로운 프로필 사진이 필요하지만 사진관을 방문하기 어려운 구직자로 설정했습니다.

  • 지원 마감 또는 면접 일정이 임박한 구직자
  • 사진관 방문에 시간·거리의 제약이 있는 사람
  • 지속적인 구독보다 필요한 순간 한 번 이용하고 싶은 사람

따라서 많은 기능을 제공하기보다 사진 업로드 → 스타일 선택 → 결제 → 생성 → 결과 활용까지 짧게 완료할 수 있는 흐름을 우선했습니다.

기획 기준

서비스의 핵심 약속을 얼굴은 본인답게 유지하고, 면접에 필요한 환경만 정돈한다로 정했습니다.

필요한 순간 한 번만 결제

면접 사진은 지속적으로 사용하는 서비스가 아니라고 판단해 구독 대신 3,900원 단건 결제로 구성했습니다.

AI 생성 결과에는 편차가 있을 수 있기 때문에 한 번의 결과만 제공하기보다 최대 2회의 생성 기회를 제공해 결과 선택의 여지를 두었습니다.

결과에 필요한 선택지만 제공

생성 과정에서는 사진 유형, 배경, 의상, 성별처럼 결과에 직접 영향을 주는 항목만 선택하도록 구성했습니다.

사진 유형은 일반적인 정면 면접 사진과 조금 더 자연스러운 상반신 면접 사진으로 구분하고, 배경과 의상 역시 지원서에 활용하기 쉬운 선택지를 중심으로 제한했습니다.

생성보다 실제 활용까지

사진을 생성하는 것에서 끝내지 않고, 결과를 증명사진 3:4, 프로필 4:5, 정사각형 1:1 비율로 조정할 수 있도록 했습니다.

확대와 위치도 직접 조절할 수 있게 해 AI 이미지를 만드는 것보다 실제 지원 과정에서 사용할 수 있는 결과물을 만드는 것에 초점을 맞췄습니다.

와이어프레임

공개 페이지, 사용자 작업 공간, 결제 흐름과 운영자 화면까지 서비스 전체 범위를 설계했습니다.

주요 기능

핵심 사용 흐름

사용자가 한 번에 많은 설정을 마주하지 않도록 사진 제작 과정을 단계별로 나눴습니다.

각 단계에서는 현재 선택한 값과 다음 행동을 명확하게 보여주고, 결제 전에는 원본 사진과 모든 설정을 다시 확인할 수 있도록 구성했습니다.

결제 전에 결과를 예측할 수 있도록

AI 이미지 상품은 결제 전 실물을 확인할 수 없기 때문에 사용자가 무엇을 구매하는지 이해하는 과정이 중요했습니다.

결제 화면에서 업로드한 원본과 선택한 사진 유형, 배경, 의상, 성별을 한 번에 다시 보여주고, 잘못 선택한 항목은 결제 전에 수정할 수 있도록 했습니다. 상품 가격과 생성 조건도 같은 화면에 배치해 선택한 설정과 결제 대상이 분리되어 보이지 않도록 구성했습니다.

기다림을 작업 상태로 바꾸기

AI 생성은 요청 직후 결과가 나오지 않습니다. 이 시간을 단순한 로딩 화면으로 처리하면 사용자는 요청이 정상적으로 접수됐는지, 화면을 닫아도 되는지 알기 어렵습니다.

그래서 결제와 생성 요청을 분리하고, 작업 상세 화면에서 요청 중·처리 중·완료 상태를 확인할 수 있도록 했습니다. 기존 결과는 유지한 채 새 결과가 추가되도록 구성했으며, 남은 생성 횟수와 실패 횟수도 함께 표시했습니다.

생성 결과를 실제 사진으로 다듬기

완성된 사진은 한 장만 보여주지 않고 두 번의 생성 결과를 나란히 비교할 수 있도록 했습니다. 사용자는 원하는 결과를 선택해 바로 다운로드하거나, 사용처에 맞게 구도를 다시 조정할 수 있습니다.

구도 조정 화면에서는 증명사진 3:4, 프로필 4:5, 정사각형 1:1 비율을 제공했습니다. 확대와 좌우·상하 위치, 흰색 테두리를 직접 조절할 수 있고, 편집본을 저장해도 생성 원본은 유지되도록 했습니다.

첫 결과가 만족스럽지 않은 경우에는 남은 생성 횟수 안에서 원본 사진을 교체하거나 설정을 바꿔 다시 생성할 수 있도록 했습니다. 결제를 반복하게 하기보다 한 번 구매한 작업 안에서 결과를 개선할 기회를 제공했습니다.

설계 및 구현

아이디어 검토에 머무르지 않고 실제 결제와 AI 생성이 가능한 수준까지 전체 제품을 구현했습니다.

Next.js와 React로 사용자 화면을 구성하고 FastAPI 기반 백엔드에서 회원, 상품, 주문, 결제, 사진 생성 작업을 관리했습니다.

회원 인증과 이메일 확인부터 상품·주문·결제, 사진 업로드, 비동기 AI 생성, 진행 상태 확인, 결과 관리와 다운로드, 운영자 관리 화면까지 실제 서비스 운영에 필요한 흐름을 연결했습니다.

특히 AI 생성은 처리 시간이 필요한 작업이기 때문에 요청과 생성을 분리하고 별도 비동기 작업으로 처리했습니다. 결제 상태와 생성 횟수도 서버에서 관리해 중복 요청이나 실패 상황에 대응할 수 있도록 구성했습니다.

업로드한 사진은 개인정보 보호를 고려해 보관 기간을 7일로 제한하고 이후 자동으로 정리되도록 설계했습니다.

결과

출시하지 않은 이유

기능 구현과 결제 연동까지 완료했지만 최종적으로 공개 출시는 보류했습니다.

제품의 핵심 약속은 사용자의 얼굴은 유지하면서 촬영 환경만 바꾸는 것이었습니다.

그러나 반복 테스트 과정에서 입력 사진과 생성 결과 사이의 얼굴 특징이 달라지는 사례가 발생했고, 사용자와 입력 사진에 따라 결과 품질의 편차도 컸습니다.

일부 테스트에서는 충분히 좋은 결과가 나왔지만, 중요한 것은 가장 잘 나온 결과가 아니라 일반 사용자가 비용을 지불했을 때 일정 수준 이상의 결과를 안정적으로 받을 수 있는가라고 판단했습니다.

잘 나온 일부 결과만 기준으로 서비스를 출시하는 것은 사용자의 중요한 지원 일정에 품질 위험을 넘기는 일이라고 보았습니다.

따라서 기능의 완성 여부와 별개로 제품의 핵심 품질 기준을 충족하지 못했다고 판단해 공개 출시를 보류했습니다.

회고

PhotoAI를 만들면서 동작하는 소프트웨어와 판매할 수 있는 제품은 다르다는 점을 배웠습니다.

처음에는 사진 생성 기능을 구현하는 것이 가장 큰 문제라고 생각했습니다. 하지만 실제로 결제부터 결과 다운로드까지 연결해보니 더 중요한 문제는 사용자가 비용을 지불했을 때 약속한 품질을 얼마나 안정적으로 제공할 수 있는가였습니다.

또한 사용자가 서비스를 이용하는 전체 과정은 AI 모델 하나로 완성되지 않았습니다. 가격, 생성 횟수, 선택 항목, 결제 전 확인, 생성 대기 상태, 결과 비교, 구도 조정과 같은 작은 결정들이 모여 하나의 제품 경험을 만들었습니다.

결국 이 프로젝트에서 가장 중요한 결과는 출시 자체보다 핵심 품질 기준을 정하고, 그 기준을 충족하지 못했을 때 출시하지 않는 선택까지 제품의 일부로 판단한 경험이었습니다.
